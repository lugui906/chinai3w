ChinAI3 Windows 版

把 TSAI-OS 上的 AI 桌面助手带到 Windows。用系统自带的 Edge WebView2 承载同一套界面， 内置 Node 运行时与 opencode 引擎，一键安装、装完即用。

Windows 10 / 11 · x64 Edge WebView2 原生外壳 内置 AI 引擎 · 离线可用 免管理员安装
下载 MSI 安装包 下载 ZIP 免安装包 GitHub 仓库

最新版 v1.0.0 · 安装包 chinai3-1.0.0-x64.msi · 免安装包 chinai3-win-1.0.0.zip

为什么是 Windows 原生版

GTK4 / WebKitGTK 在 Windows 上要 MSYS2 + gvsbuild 才能拿到 PyGObject，部署极重。 ChinAI3 的界面本来就是 Flask 提供的网页，所以 Windows 版直接用系统自带的 WebView2 承载同一套页面， 视觉与功能一致，且无需 GTK。

Edge WebView2 原生外壳

Windows 11 自带 WebView2 运行时，无需额外安装即可获得与 Linux 版一致的液态玻璃界面。

内置 AI 引擎，装完即用

随包内嵌 Node 运行时与 opencode v2，目标机无需再装 Node.js / npm，首次对话即可用。

离线安装包

发行包自带嵌入式 Python 3.12、pip 与全部依赖 wheel，无网也能完成安装。

与 TSAI-OS 同源

同一套 server.py / backends.py 与 Web UI，仅加 Windows 分支，功能对齐。

免管理员安装

MSI 按当前用户装到 %LOCALAPPDATA%\Programs\ChinAI3，自动建快捷方式并加入 PATH。

模型与 API Key 管理

设置里一键切换模型、增删各 provider 的 API Key，Key 只保存在本机。

安装只需两步

推荐用 MSI 安装包；也可以解压 ZIP 后运行一键脚本。

1

下载并安装

双击 chinai3-1.0.0-x64.msi 按提示完成安装（免管理员）。

msiexec /i chinai3-1.0.0-x64.msi /qn
2

启动使用

从开始菜单或桌面快捷方式启动 ChinAI3，在「设置 → 模型 / API Key」里填好 Key 即可对话。

★

ZIP 免安装方式

解压发行包后，在 PowerShell 里跑一键安装脚本（离线复用包内 vendor/）：

powershell -ExecutionPolicy Bypass -File install.ps1
